## 📌 Descripción del Proyecto
Este repositorio contiene el código fuente del Trabajo Terminal enfocado en el desarrollo de un prototipo funcional que asiste a docentes en la evaluación y optimización de su material didáctico (.pptx). Utilizando algoritmos de procesamiento de lenguaje natural y la API de Google Gemini, el sistema evalúa métricas de calidad, asiste en la gestión del tiempo durante la exposición y genera recomendaciones personalizadas.

## 🚀 Características Principales (Prototipos Evolutivos)
El desarrollo se divide en 3 fases iterativas:
* **Prototipo 1 (Análisis Previo):** Extracción de texto y evaluación estática basada en 6 métricas (Complejidad, Densidad, Similitud, Estructura, Tiempo e Hilo narrativo).
* **Prototipo 2 (Sesión en Vivo):** Doble vista sincronizada (Docente/Alumno), cronometraje por diapositiva y alertas de ritmo en tiempo real.
* **Prototipo 3 (Retroalimentación):** Consolidación de datos y generación de un Informe de Rendimiento cualitativo mediante IA.

## 🛠️ Stack Tecnológico
* **Frontend (Capa de Presentación):** [Ej. React.js / Vue.js]
* **Backend (Capa de Lógica):** [Ej. Python 3.10+, FastAPI]
* **Base de Datos (Capa de Datos):** [Ej. PostgreSQL / SQLite]
